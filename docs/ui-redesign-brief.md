# Logi Lite Mac UI 重构讨论

日期：2026-10-14。状态：macOS Tauri 初版已实现，见 [实现记录](tauri-macos-preview.md)。

## 已确认

用户选择：**类似 Options+，鼠标大图，点击按键配置**。

保留当前已验证的普通按键映射、打开 App、调度中心、DPI 和滚轮设置。手势功能因用户反馈难用已移除，记录见 [gesture-button-experiment.md](gesture-button-experiment.md)，不纳入此次设计。

用户希望新 UI 同时适用于 Windows 和 macOS。目前两端分别使用 Win32 与 AppKit 界面，共享 Rust 配置和 HID++ 协议；共用 UI 需要新增界面层及两端桥接，不能直接复用现有 Swift 界面。

## 跨平台界面建议（尚未选定技术方案）

建议用本地 HTML/CSS/TypeScript 构建同一套鼠标大图、按键热点和配置面板，由 macOS WKWebView 和 Windows WebView2 承载；也可评估 Tauri 作为窗口及通信框架。界面资源随应用打包，离线可用。Windows WebView2 运行时依赖需要在打包时检测并处理。

共享界面通过统一命令与状态接口调用各平台后端，保留现有输入监听、HID 通信、配置持久化、菜单栏／托盘常驻与紧急暂停机制。Mac 输入权限引导独立保留；Windows 快捷键使用 Ctrl/Win，Mac 使用 Cmd。系统动作由平台提供能力列表，避免将 Mac 的“打开 App／调度中心”直接套到 Windows。Windows 新 UI 和真实鼠标通信需要在 Windows 环境单独构建、验证。

## 建议的页面与交互

- 顶部：鼠标型号、蓝牙连接状态、电量及映射启用／暂停开关。
- 按键页：以鼠标大图为主体，侧键和中键设可点击标记；点击后高亮对应位置，在右侧打开动作配置面板。
- 动作面板：显示选中的实体按键；用“默认”“禁用”“系统动作”“快捷键”等用户可理解的分类选择动作。快捷键提供录制控件，减少手动输入。
- 指针与滚轮页：真实 DPI 数值及设备支持范围、SmartShift 灵敏度百分比、自由／段落／SmartShift 模式。硬件设置提供应用后回读反馈。
- 高级设置：权限状态、重新连接／刷新、导出诊断；原始 JSON 收到可展开的诊断区。
- 在保存或应用处给出明确成功／失败状态，保留菜单栏常驻、暂停和退出入口。

## 设备状态与硬件设置交互

现有测试界面要求先手动读取并验证设备，成功后开放控件；应用操作会在后端重新验证目标并写入、回读。正常成功后无需每次手动刷新，但通信失败会锁定硬件控件，需重新读取。

新 UI 建议在启动及设备接入／重连后自动只读识别目标、功能、范围和当前值，成功后开放硬件控件。断开时使设备状态失效并禁用写入；休眠或临时通信失败提示唤醒并提供重试，避免反复弹窗。通过设备连接事件更新状态；不为更新电量持续高频探测休眠设备。

用户调整的是待应用值，后台读取的实际值单独维护，不能覆盖尚未提交的编辑。点击应用时只发送更改项，后端串行校验目标和支持范围、写入、回读，再显示实际结果。失败或部分成功时保留待应用值并明确反馈。刷新入口保留在设置／诊断内，作为手动恢复方式。启动及重连自动读取，不自动重写上次硬件设置；是否增加“重连后恢复设置”另行讨论。
