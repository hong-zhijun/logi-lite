# 手势按钮实验记录（已移除）

日期：2026-10-14。适用：Logi Lite Mac 版，蓝牙 MX Anywhere 3。

## 决定与用户反馈

用户试用后反馈：“好难用”，并明确要求移除。现已放弃此轮实现；仅保留本记录，不作为当前软件功能。没有进一步确认具体是哪种方向、距离或指针表现造成难用，不能将猜测写成已确认原因。

本轮实现是本项目自定义方向手势，不是对 Options+ 手势算法的完整复现。Options+ 资源中的 `Gestures` 与 `SLOT_NAME_GESTURE_BUTTON` 只确立功能入口存在。

## 历史设计与配置

以下为移除前的行为和配置，当前版本不再提供。

### 手势按钮

将一个侧键（或中键）设为 `手势按钮`，展开手势设置，设置五个动作后保存。多个手势按钮共用一组设置，点按和方向动作可选 `禁用`、`打开 App`、`调度中心` 或支持的快捷键，不能使用 `默认` 或再次嵌套 `手势按钮`。

| 手势 | 默认配置值 | 效果 |
|---|---|---|
| 不移动、松开 | `禁用` | 不执行动作；可改为快捷键或系统动作 |
| 向上移动、松开 | `调度中心` | 打开全部窗口概览 |
| 向下移动、松开 | `打开 App` | 打开应用列表 |
| 向左移动、松开 | `Ctrl+Left` | 切换左侧桌面，依赖系统快捷键 |
| 向右移动、松开 | `Ctrl+Right` | 切换右侧桌面，依赖系统快捷键 |

触发距离默认 **40**，可设置 **15～300**；这是本程序选择的相对移动阈值，不是 Options+ 的官方范围或物理毫米数。鼠标 DPI 和系统事件输出会影响手感。数值越低越容易触发。

按住时累计相对移动并拦截对应移动事件；第一个达到距离且明显偏向一个方向的移动会锁定选择，松开仅执行一次。小幅抖动仍按点按处理；明显斜向但未选定方向的移动不会触发点按。按 Esc、点击其他按键、滚动滚轮、暂停、修改配置、系统休眠／切换会话或持续按住达到 10 秒会取消。取消后恢复移动处理，松开不会补发动作。检测到释放事件丢失时也会取消当前手势。

配置文件新增可选的 `gestures` 对象，旧配置不包含它时自动使用以上默认设置，不改变原来的按键动作：

```json
{
  "version": 1,
  "enabled": true,
  "back": "手势按钮",
  "forward": "打开 App",
  "middle": "默认",
  "gestures": {
    "click": "禁用",
    "up": "调度中心",
    "down": "打开 App",
    "left": "Ctrl+Left",
    "right": "Ctrl+Right",
    "distance": 40
  }
}
```

手势映射仍作用于所有鼠标；按住期间其他指针设备的移动也可能进入这次手势。真实蓝牙鼠标的手感和指针抑制效果需要用户测试，目前没有执行 Options+ 的手势算法或声称与它完全一致。

## 代码与验证记录

- `Input.swift`：增加 `GestureTracker`，按住时累计相对移动；主方向领先另一轴 1.35 倍且达到阈值时锁定；松开执行一次。
- 监听鼠标移动、侧键拖动、其他点击和滚轮；拦截手势期间移动。取消后将仍被系统归为侧键拖动的事件转换为普通移动。
- 10 秒超时；每 0.25 秒检查物理按键状态，持续检测到释放 0.5 秒后取消丢失释放事件的会话。
- 队列里的系统动作使用配置修订号检查，避免暂停后执行。
- UI 提供折叠面板、点按及四个方向的动作和触发距离。
- 21 项 Rust 测试及原生解析／配对／手势／HID 测试通过；包含旧配置迁移、四方向、抖动、斜向返回、首次方向锁定、重复释放、同时按键、取消和超时。
- UI 启动检查通过。上述自动验证不能保证真实鼠标的手感；用户实际体验不符合预期。

## 移除范围与兼容处理

移除软件中的手势动作选项、配置面板、识别算法、移动事件监听与拦截、定时释放检测，以及专用测试。普通侧键映射、打开 App、调度中心与硬件设置保留。

加载旧配置时忽略旧 `gestures` 对象，将设置为 `手势按钮` 的按键恢复为 `默认`，并暂停映射，待用户重新配置后启用；其他按键设置保留。后续保存不再写入 `gestures`。不会在移除过程中直接改写用户已有配置文件。

## 若未来重新考虑

需先确认用户希望解决的具体操作，以及难用发生在按住、识别、松开还是指针移动阶段，再评估模型、视觉反馈和真实设备测试。当前 UI 重构讨论不包含恢复手势功能。
