# Tauri macOS 初版

更新：2026-10-15。macOS 0.2 使用 Tauri 2 + 本地 HTML/CSS/JavaScript。旧 AppKit 设置窗口已删除；Windows 已接入同一 Tauri 前端，使用独立 Windows 后端。

## 页面与运行

- 顶部透明标题栏，与主界面同色，保留 macOS 红黄绿按钮和拖动区域。
- 鼠标首页：居中的 MX Anywhere 3 斜侧面图，后退、前进、中键及指针与滚轮共四个独立热点；点击打开对应右侧面板，关闭恢复居中。移除侧栏与软件名称／版本号。界面初始尺寸 1080 × 800，最小宽度 920，高度固定为 800；卡片内容不足以容纳时允许内部滚动。
- 指针与滚轮面板：从首页鼠标热点打开，设备能力决定的 DPI 范围／步长、滚轮模式和 SmartShift 百分比、可调阻力设备的滚动力度 1–100%；仅提交更改项，串行验证、写入和回读。
- 设置页：权限、常驻说明、手动刷新和导出诊断。缺少权限时，在设备配置区持续显示毛玻璃遮罩和授权入口；未授权设备页面使用 inert 阻止鼠标和键盘操作，设置页始终可访问。系统最终授权由用户在 macOS 完成；首次授权后自动解锁并默认启用映射，设置页保留手动暂停开关；授权提示与“鼠标映射”标题同行，隐藏提示不改变卡片高度。撤销权限后重新锁定并停止监听，原来启用的映射在重新授权后恢复，手动暂停仍保持暂停。
- UI 静态资源编译进应用，无运行时本地 HTTP 服务或外部页面。IPC 仅开放本程序命令和窗口拖动，配置／硬件写入由原有 Rust 与 Swift 校验。
- 鼠标输入在主线程原生事件监听运行，HID 工作在后台串行线程。关闭窗口隐藏而不退出，菜单栏可重新打开、暂停和退出，紧急暂停不依赖 WebView 焦点。
- 连接检测为每 4 秒只读检查 HID 元数据；接入变化后自动探测。通信失败时窗口可见期间每 8–30 秒重试；成功后约每 15 秒单独读电池，不发现 DPI／滚轮能力、不覆盖未保存草稿，显示充电中或已充满。断开或失败使写入控件失效。未应用的编辑与读取状态分开保存，重连不自动写入设置。

## 代码入口

- `ui/`：可复用前端、鼠标图片和样式。
- `src-tauri/`：macOS Tauri 容器、菜单栏与原生请求桥接。按条件编译接入 Mac / Windows 后端；本次新增的分类动作、选应用、水平滚动及滚动力度界面仅在 Mac 开放。
- `src/platform/macos/native/Runtime.swift`：配置、输入与权限；复用 `Input.swift`、`HID.swift`，Rust C ABI 继续负责配置和 HID++。
- `scripts/build-macos.sh`：构建、生成 app、ad-hoc 签名；`scripts/check-macos.sh` 检查共享后端、新容器和前端语法。

## 验证与限制

根项目 27 项 Rust 测试、Swift 输入解析／按键配对和离线 HID 描述符测试通过。新容器执行 `cargo clippy -- -D warnings`。应用 `--smoke-test` 检查页面加载、鼠标图、热点比例、选择按键及导航；该模式不读取用户配置、不安装输入监听、不申请权限、不与鼠标通信。实际鼠标映射与硬件设置仍由用户测试新 UI 下的操作结果；旧后端已验证不等于新界面端到端验证完成。

系统授权可能因本地 ad-hoc 签名变化需要重新确认。当前不是公证发布版本；仅构建当前 Mac 原生架构。

实际启动已确认首次授权引导显示、旧配置可加载、后台自动识别到蓝牙 MX Anywhere 3。当前系统对新版可执行文件报告辅助功能／输入监控未授权，打开 HID 端点返回 `-536870174`；因此此次未执行硬件写入或物理按键映射端到端测试。需要用户在系统设置确认新版授权后再测试。最终应用自检还验证后台状态刷新不会覆盖未保存的按键草稿，配置文件哈希自检前后相同。

界面调整：使用灰白背景与紫色强调色，按键页启动时无选中按键且隐藏动作面板；点击图片热点才展示面板，可通过关闭按钮回到未选择状态，关闭不丢弃未保存草稿。右侧卡片隐藏滚动条，仍支持触控板、滚轮和键盘滚动。

精简布局：标题栏只保留系统窗口按钮与拖动区域，移除品牌、标语、导航分区标题、按键页说明及底部文字选择按钮。内容区左、右、下留白为 28pt，顶部保留 28pt 系统标题栏空间加 8pt 间距，设备行从窗口顶部 36pt 开始；底部状态栏移除。连接、电量与映射状态集中在右上角同一胶囊，映射状态可点击进入设置页；圆形设置按钮位于状态胶囊右侧，点击打开设置，再次点击返回鼠标首页。映射开关移至设置页，首次授权后默认启用；权限要求不变。

图标与可读性：采用用户指定的 `logi-lite-app-flat-ui-bg.png`，原图保存在 `src-tauri/icons/logo-source.png`。`python3 scripts/prepare-icons.py`（需要 Pillow）保留指定图片已有的底板和外边距，生成左上角 logo、PNG 和 ICNS 程序图标；菜单栏从同一新 logo 提取鼠标轮廓生成透明模板图标，提取结果保存为 `tray-source.png`。设置与动作图标采用统一 24 × 24 坐标，所有 SVG 显式声明 viewBox。非标题字号整体增加 2px，标题尺寸保持不变。两个设备设置面板移除按键位置、动作效果、滚轮手感等说明，仅保留标题、控件、未保存状态及设备状态；四边内边距统一 24px。

图标刷新：打包时以 ICNS 内容哈希命名图标资源，Info.plist 引用对应名称；额外保存 `app-logo.png`。macOS 后端启动时将该 PNG 设置为 NSApp.applicationIconImage，减少同一路径反复构建导致旧图标缓存的影响。隔离自检确认当前应用成功加载这份图标；已运行的旧进程需退出后重开才能执行新启动逻辑。

交互细化：设置页也隐藏滚动条并保留滚动；按键面板打开／关闭采用透明度与位移动画，鼠标展示区域同步调整宽度，面板保持固定宽度避免文字挤压；快速切换开关由 CSS 过渡衔接。系统“减少动态效果”开启时禁用这些过渡。新权限遮罩替代首开弹窗，不依赖“已看过引导”的标记；未授权不自动探测硬件，设置页仍允许手动重试但权限不足时不发送探测。

映射启用偏好：`MappingActivation.swift` 管理首次启用和权限恢复，`desktop.mappingChoice.v1` 区分默认迁移与后续用户选择；首次升级也在授权后默认启用。完整权限具备才安装监听，单次安装失败不在每次刷新重试。手动／紧急暂停持久化关闭；正常退出使用独立 shutdown 操作停止监听但不改写启用偏好。隔离界面自检不进入真实自动启用路径；独立 Swift 测试覆盖首次授权、重授权、失败限次和暂停保持，实际物理侧键与系统授权流程仍需用户测试。

入口精简：指针与滚轮入口位于鼠标左上侧，用引线指向滚轮；入口下分行显示已确认的 DPI 与滚轮模式，未连接或读取未确认时不展示旧值。中键名称统一为“中键（鼠标滚轮）”。DPI 使用滑条与只读数值，实际状态与尚未应用的滑条草稿分开。设置页移除顶部标题／关闭按钮、重复权限说明与“请求输入权限”按钮；权限遮罩的“去授权”和每项未授权权限的“去授权”入口保留。

状态与刷新：右上状态胶囊顺序为连接、映射、电量，胶囊右侧依次为圆形刷新与设置按钮。刷新按钮调用原有只读设备探测并回读状态，通信时禁用并显示转动反馈，缺少必要权限时禁用；硬件面板不再单独放置重新读取按钮。鼠标旁文案简化为“DPI 1000”。设置页逐项显示权限状态，未授权文字为橙色；“去授权”打开相应系统权限页面，对应权限授予后隐藏该按钮，撤销后恢复。

视觉细化：刷新图标改为单箭头圆弧，关闭图标使用居中的 SVG 交叉线。权限卡移除就绪徽章，逐项已授权显示绿色、未授权保持橙色。保存状态合并进操作按钮：待应用为橙色感叹号，保存／同步完成为绿色勾号，通信中为紫色转动图标；无修改时按钮禁用且保留状态色。常规设置内容在 800pt 固定高度内无需滚动，展开技术信息仍允许滚动。

2026-10-15 动作扩展：后退／前进侧键各自提供独立的水平滚动开关（按住侧键＋滚轮），中键不显示此项；支持原生选择 .app、“更多”的分类二级下拉菜单；快捷键只读框聚焦即录制，失焦停止，无单独录制按钮。应用路径失效不会使其余映射配置加载失败，触发时提示错误。媒体／音量／亮度发送系统媒体键，系统设置与计算器通过 NSWorkspace 打开，其他常用动作发送菜单所列快捷键。硬件写入仍只在点击应用时发生，模式与灵敏度变更保留阻力，单改阻力保留模式与阈值，全部回读验证。硬件按钮完成文案统一为“已保存”。

交互修订：水平滚动与普通点击动作分开保存，无滚动时松开执行原动作，产生滚动则消耗该次点击。指定应用同时在动作卡片和选择区显示 NSWorkspace 提取的真实图标，重启后按保存路径恢复图标。分类选择器改为统一灰紫样式的自定义弹出列表，支持选中勾号、方向键、Home／End、Esc、失焦收起和边界定位；保留两级分类。设置页双向淡入／位移动画，快速切换取消上一次动画，离开页立即 inert，系统减少动态效果时跳过动画。
