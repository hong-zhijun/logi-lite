# Logi Lite 0.1 — Windows 鼠标测试版

针对 MX Anywhere 3 的轻量用户态工具。基础鼠标输入继续使用 Windows 自带驱动；设置窗口关闭后，程序保留在通知区托盘。顶部模式键改功能和按应用设置留待后续版本。

## 首版功能

- 托盘常驻、双击打开设置、右键暂停或退出；关闭窗口只隐藏界面。
- 后退侧键、前进侧键、滚轮中键：默认、禁用、键盘快捷键；支持 Ctrl / Alt / Shift / Win、字母、数字、F1–F24 及常用导航键。
- 本地保存快捷键，启动时恢复；`Ctrl+Alt+Shift+F12` 临时暂停或恢复。
- Logitech HID 设备识别；读取可通信的 Anywhere 3 电量、DPI 支持范围和滚轮设置。
- 实验性硬件设置：DPI、自由滚动、棘轮滚动、SmartShift 阈值。应用前重新确认型号，写入后回读确认。
- 导出诊断，记录设备能力与错误；不记录输入内容或鼠标轨迹。

**首版快捷键采用全局模式，会影响所有鼠标的对应侧键和中键。** 初次启动默认关闭，先选择动作，再勾选并点击“保存并应用快捷键”。硬件 DPI / 滚轮写入只针对识别出的目标鼠标。

## 今晚如何试

1. 双击 `LogiLite.exe`，连接你平时使用的蓝牙或接收器。开机后需手动启动本版程序。
2. 测试自定义键或硬件设置前，先退出 Options+，避免双方重映射或覆盖设置。关闭官方窗口未必会退出后台；可在任务管理器确认 `logioptionsplus_agent.exe` 是否仍运行。本工具不会自动结束它。
3. 先把后退侧键设置为 `Ctrl+C`、前进侧键设置为 `Ctrl+V`，中键保留“默认”；勾选启用并保存。在记事本选中文字，用侧键测试复制、粘贴。
4. 点击窗口的 ×，确认通知区仍有图标，再测试侧键。右键托盘选择暂停，应恢复原行为；恢复后再测试。右键“退出 Logi Lite”才会彻底退出。
5. 点击“查找 / 刷新设备”。成功识别并读取能力后，对应硬件控件才会开放。电量通过手动刷新更新。
6. DPI 先试一个设备支持的数值；滚轮先试自由 / 棘轮，再试 SmartShift。阈值允许 1–49；它只在 SmartShift 模式使用。本版保留现有滚轮力度，不修改高分辨率滚轮报告模式。
7. 如果探测失败或功能不生效，点击“导出诊断”，将结果留作下一轮修复依据。

普通 Anywhere 3 通常使用 Unifying 或蓝牙；3S / 商务版可能使用 Bolt。本版尝试系统暴露的 HID++ vendor collection；如果蓝牙只暴露专有 GATT 通路，首版可能无法读取或修改硬件设置。不会猜测端点或在未识别型号时写配置。

## 设置保存与退出

设置目录：`%LOCALAPPDATA%\LogiLite`。

- `config.json`：快捷键配置，自动加载。暂停状态只在当前运行期间有效。
- `hardware-settings.json`：已成功应用并回读的硬件设置记录。首版不会在启动 / 重连时自动重写，设备若恢复默认，请刷新后重新应用。
- `diagnostic.json`：手动导出的设备元数据、读取状态和错误。

彻底退出后，自定义快捷键不再由本程序处理。硬件 DPI / 滚轮设置能保持多久取决于固件；关机、省电或重连可能恢复默认。基础输入由 Windows 继续处理。

## 已完成验证与限制

配置、输入状态机、HID++ 包、DPI 范围、SmartShift 写入和错误处理有自动测试。Windows 桌面自检验证了窗口、托盘、关闭后常驻、重入暂停和退出；实际执行过只读 HID 元数据枚举。

**真实鼠标未连接，DPI / 电量 / 滚轮通信和物理侧键的端到端行为尚未实测。** 协议测试使用模拟报告，不等于固件兼容验证。蓝牙与接收器都需要实际确认。

普通权限 `SendInput` 对管理员窗口、UAC 和部分游戏有限制。首版执行一次完整快捷键，而不是“按住鼠标等于一直按住键盘键”。若原侧键已经被其他软件接管，应先暂停那个软件。

无设备连接、映射关闭的短时测试约 11.5 MiB 累加工作集、2.1 MiB 私有提交量、5 个线程；这是本机短样本，不是完整性能对照或连接设备后的保证。

## 构建和开发检查

Windows x64、Rust MSVC 工具链：

```powershell
cargo test --offline --target-dir target
cargo clippy --all-targets --offline --target-dir target -- -D warnings
cargo build --release --offline --target-dir target
```

依赖已缓存时可离线构建；首次取得依赖需正常使用 Cargo。产物为 `target\release\logi-lite.exe`。本项目设置 MSVC CRT 静态链接；运行不需要 Python、Qt 或浏览器运行时。

只读元数据输出：`LogiLite.exe --diagnose <输出文件>`。
桌面自检：`LogiLite.exe --smoke-test <结果 JSON>`，使用默认关闭的映射、保存窗口截图并自动退出，不发送 HID++ 请求。

协议参考与覆盖限制见 `analysis/hidpp-implementation.md`；本机官方程序调查见 `analysis/Logi-Options-Plus-分析报告.md`。
